MLE via Quotient Estimator

Display

This section presents functional estimator via maximum likelihood form.

In this section, we consider the following situation of small noise asymptotic statistical inference.

  • Let \(Z\sim \mathcal{N}(0,\K)\) and \(K\) be the covariance function of \(Z\) corresponding to \(\K\).
  • We observe \(X^ arepsilon=h_0+ arepsilon Z \sim N(h_0, arepsilon^2 \K)\) for some \( arepsilon>0\), where
    • Let \(\K\) (resp.\ \(K\)) be the known covariance operator (resp.\ covariance function).
    • Let \(h_0 \coloneqq h_{ heta_0}=\K \mu_{ heta_0}\in \HP\) be an unknown true mean function with \(\mu_0 \coloneqq \mu_{ heta_0}\in\MM\) which are parameterized for \( heta_0\in \Theta\).
Notation
\[ \MMM\coloneqq \MM /\ker \K, \]

with the quotient norm.

In order to define estimators on the quotient space \(\widetilde{M}\), the following properties are important.

Proposition

Then, the map

\[ [\mu] \mapsto \innerp{\mu,y} - \frac12 \innerp{\mu,\K\mu} \]

is well-defined; that is, it does not depend on the choice of a representative \([\mu]\). Moreover, the map is continuous with respect to the quotient norm.

Proof

let \(\mu_1\) and \(\mu_2\) satisfy \(\mu_1-\mu_2\in\ker \K\). For fixed \(y\in\overline{\K(\M)}\), take a sequence \(\{\nu_n\}\subset\MM\) such that \(\K\nu_n\) converges to \(y\) in \(C[0,T]\). Since \(\K\) is symmetric, it follows that

\[ \begin{aligned} \innerp{\mu_1,y} - \innerp{\mu_2,y} &= \innerp{ \mu_1 - \mu_2 , \lim_{n\to\infty} \K \nu_n } = \lim_{n\to\infty} \innerp{ \mu_1 - \mu_2 , \K \nu_n } \\ &= \lim_{n\to\infty} \innerp{ \nu_n , \K (\mu_1 - \mu_2) } = 0, \end{aligned} \]

and that

\[ \innerp{ \mu_1,\K\mu_1 } - \innerp{ \mu_2,\K\mu_2 } = \innerp{ \mu_1+\mu_2,\K(\mu_1-\mu_2) } = 0, \]

which shows the well-definedness.

For the continuity, we suppose that \([\mu_n]\to[\mu]\) in \(\MMM\) as \(n\to \infty\). Then,

\[ \begin{aligned} &\abs{ \qty( \innerp{\mu_n,y} - \frac12 \innerp{\mu_n,\K\mu_n} ) - \qty( \innerp{\mu,y} - \frac12 \innerp{\mu,\K\mu} ) }\\ &\qquad\qquad\qquad\qquad = \abs{ \innerp{ \mu_n-\mu, y } } + \frac12 \abs{ \innerp{ \mu_n+\mu, \K (\mu_n-\mu) } } \end{aligned} \]

When we use \(\{\nu_m\}\) taken above again, it follows from Lemma that

\[ \begin{aligned} \abs{ \innerp{ \mu_n-\mu, y } } &= \abs{ \innerp{ \mu_n-\mu, \lim_{m\to\infty} \K \nu_m } } = \lim_{m\to\infty} \abs{ \innerp{ \mu_n-\mu, \K \nu_m } } \\ &\leq \lim_{m\to \infty} \SN{\K \nu_m} \MTN{[\mu_n-\mu]} = \SN{y} \MTN{[\mu_n]-[\mu]}\to 0,\quad n\to \infty. \end{aligned} \]

Moreover, it follows that

\[ \abs{ \innerp{ \mu_n+\mu, \K (\mu_n-\mu) } } \leq \OPN{\K} \MTN{[\mu_n+\mu]}\MTN{[\mu_n-\mu]}\to 0, \]

as \(n\to \infty\). This ends the proof.

According to Proposition, we make a contrast function \(\widetilde{\Phi}_\varepsilon\) to estimate \(\mu_0\) as follows:

\[ \widetilde{\Phi}_{\varepsilon}([\mu]) \coloneqq \innerp{ \mu,X^\varepsilon } - \frac12 \innerp{ \mu,\K\mu }. \]

Note that

\[ \widetilde{\Phi}_{\varepsilon}([\mu]) \asconv \widetilde{\Phi}([\mu]) \coloneqq \innerp{\mu,h_0} - \frac12\innerp{ \mu,\K\mu } \quad (\varepsilon\to0). \]
Proposition
Proof

Since

\[ \innerp{\mu,\K\mu_0} - \frac12 \innerp{\mu,\K\mu} = - \frac12 \innerp{\mu-\mu_0,\K(\mu-\mu_0)} + \frac12 \innerp{\mu_0,\K\mu_0}, \]

\([\mu]\in\MMM\) achieves the maximum of \([\mu]\mapsto\innerp{\mu,y} - \frac12 \innerp{\mu,\K\mu}\) if and only if \(\innerp{\mu-\mu_0,\K(\mu-\mu_0)}=0\). Thus, when \([\mu]\in\MMM\) is a maximum point, its representative \(\mu\) always satisfies

\[ \norm{I^*(\mu-\mu_0)}_{\HP}^2 = \innerp{\mu-\mu_0,\K(\mu-\mu_0)} = 0. \]

This implies that \(\K(\mu-\mu_0)=II^*(\mu-\mu_0)=0\), i.e., \([\mu]=[\mu_0]\).

Lemma

= \overline{H_{P_0}}^{\SN\cdot} = \supp P_0$.

Proof

it is sufficient to show that \(\HP\subset\overline{\K(\M)}^{\SN\cdot}\). Take an arbitrary \(h\in\HP\). Then, there exist \(z\in\XP\) and \(\mu_n\in\MM\) such that \(h=Iz\) and \(\norm{z-I^*\mu_n}_{\XP}\to0\). Since \(\K=II^*\), it follows from Proposition that

\[ \SN{h-\K \mu_0} \leq \norm{\K}_{\mathrm{op}}^{1/2} \norm{z-I^*\mu_n}_{\XP} \to 0, \]

as \(n\to\infty\).

Proposition

\(\widetilde{\Theta} \subset \MMM\) is compact and \([\mu_0] \in \widetilde{\Theta}\), then \(\displaystyle \argmax_{[\mu] \in \widetilde{\Theta}} \widetilde{\Phi}_\varepsilon(\theta)\) is nonempty.

Proof

By virtue of Proposition, we define an MLE \(\hat{h}_\varepsilon\) of the mean function via the quotient estimator \([\hat{\mu}_\varepsilon]\) as

\[ \hat{h}_\varepsilon \coloneqq \K \hat{\mu}_\varepsilon \quad \text{via} \quad [\hat{\mu}_\varepsilon] \coloneqq \argmax_{[\mu]\in \widetilde{\Theta}} \widetilde{\Phi}_\varepsilon. \]
Theorem
\[ [\hat{\mu}_\varepsilon] \asconv [\mu_0] \ \ \text{in} \ \MMM \quad \hat{h}_\varepsilon \asconv h_0 \ \ \text{in} \ \CC \ \text{and} \ \HP. \]

as \(\varepsilon\to0\).

Proof

\begin{equation}\label{eq:func_conti_contrast_uni_conv} \sup_{[\mu] \in \widetilde{\Theta}} \abs{ \widetilde{\Phi}_{\varepsilon} ([\mu])- \widetilde{\Phi}([\mu]) } = \sup_{[\mu] \in \widetilde{\Theta}} \varepsilon \abs{ \innerp{ \mu, Z } } \asconv 0 \end{equation} as \(\varepsilon \to 0\). It follows from Proposition and Proposition that, for any \(\delta>0\),

\[ \widetilde{\Phi}\left([\mu_0]\right) > \sup_{\MTN{[\mu]-[\mu_0]}\geq\delta} \widetilde{\Phi}\left([\mu]\right). \]

By the definition of \(\hat{\theta}_{\varepsilon}\),

\[ \widetilde{\Phi}_{\varepsilon}([\hat{\mu}_{\varepsilon}]) \ge \widetilde{\Phi}_{\varepsilon}([\mu_0]), \]

Thus, it follows from Proposition that \([\hat{\mu}_{\varepsilon}] \asconv [\mu_0]\) in \(\MMM\) as \(\varepsilon\to0\). By Lemma, the map \([\mu] \mapsto \K\mu\) is continuous as the map \(\MMM \to \CC\) or \(\MMM \to \HP\), and therefore, it follows by continuous mapping theorem that \(\hat{h}_\varepsilon \asconv h_0\) in \(\CC\) as \(\varepsilon \to 0\).
